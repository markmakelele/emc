# Interaction Studies

The interface experiments treat interaction as evidence of experience.

## Behaviour sequence

```text
HOVER → GLOW → OVERLAY → CLICK / PAUSE → SOUND → MODE
```

Each state tests a different relationship between attention, information density, feedback and control.

## Modes

- Light
- Dark
- Contrast
- Script / Standard

The interaction layer is deliberately kept separate from the thesis so that the same research proposition can be tested through different interface behaviours.
