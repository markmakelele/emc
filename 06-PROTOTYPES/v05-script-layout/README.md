# v05 — Script Layout

Current EMC editorial prototype.

## Study

Translates the EMC research page into a black-and-white poster/editorial field inspired by the supplied still reference.

## Included

- Fira Code type system
- Large numeric identifier
- Central editorial title
- Divided information fields
- Four-column lower study field
- Hover response retained on information sections
- Sound response retained
- Script / Standard toggle
- Script control positioned top-left

## Intent

The Script mode is a layout transformation, not a separate research argument. It tests whether the same EMC information can survive a more poster-like hierarchy.
