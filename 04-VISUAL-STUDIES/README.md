# Visual Studies

This section records visual experiments as research variables rather than final decoration.

## Current studies

- Two-column editorial hierarchy
- Fira Code typography
- Black / white contrast
- Contour and striation preservation
- Material and texture extraction
- Hue and contrast hierarchy
- Poster / still-hover composition
- Script / blackletter interface treatment

The material study is especially concerned with preserving directional striation while extracting a usable contrast hierarchy from texture and shade.
